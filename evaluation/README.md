# 日本語比較用の合成ケース

`cases.json` は、比較評価に使うオリジナルの合成12組である。`before` は原文全文、`after` は候補全文。`expected_label` は作成者の未レビュー案であり、人が確定した正解やモデルの実行結果ではない。全組に `synthetic: true` と `expected_label_origin: creator_proposal_unreviewed` を付けている。

ラベルは `decider.py` の `meaning_shift` に合わせた `preserved`、`shifted`、`needs_review`。意味保持に加え、用途で保護する語り口も対象とする。自然さや好みの評価は別に行う。

比較するときは候補の出所と期待ラベルを隠し、Flashの既定に合わせて1要求につき1質問とする。期待ラベルと理由をモデルの入力へ含めず、原文・候補・プロファイルの方針から判定させる。人による独立した確認で、作成者案自体の誤りや曖昧さも見直す。方針や閾値の調整に使ったケースはテスト用から分け、別に作った未使用の日本語セットで確認する。この12組だけで日本語校正の性能を主張しない。

原文維持の組は `before == after` である。`decider.prepare` は変更のない編集を除くため、この組の将来の評価では、候補の全文章を直接 `state.original` と `state.candidate` へ入れる評価用経路が必要になる。

2026-10-17に、固定Flash・CPU BF16・最大2,048トークンで12組と`controls.json`の対照6組を実行した。[runtime-results.json](runtime-results.json)にラベル・所要時間・実行方式を記録している。制作者期待との一致は12組中11組、対照6組中6組だった。これは未レビューの期待との照合であり、正解率ではない。曖昧な指示語の組は期待`needs_review`に対して`shifted`となった。対照の主体の並べ替えと否定の言い換えにも解釈余地があり、人の確認が必要。公式CPU FP32との一致は未確認。API送信と課金は実施していない。

評価器は全文ペアを直接渡す。製品の修正範囲・抜粋・応答検査まで含む結合確認は[STATUS](../docs/STATUS.md)を参照。期待ラベルや判定基準を結果に合わせて変更していない。
